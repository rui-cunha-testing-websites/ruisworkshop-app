# Rui's Workshop: Android app

Download the latest app: **[RuisWorkshop.apk](https://github.com/rui-cunha-testing-websites/ruisworkshop-app/releases/latest/download/RuisWorkshop.apk)**

Rui's Workshop is a D&D 2024 character builder and sheet with shared campaigns. It also runs in the browser at
https://ruisworkshop.web.app, where the Home page has install steps.

## Installing

1. Open the link above on your Android phone and download the file.
2. Open it. If Android asks, allow your browser to install apps.
3. If Play Protect warns about an unknown app, tap **More details → Install anyway**: it's a private app, not from the Play Store.
4. Open Rui's Workshop and sign in.

To update, download the latest version and install it over the old one; nothing is lost.

This repository only holds the app downloads (see [Releases](https://github.com/rui-cunha-testing-websites/ruisworkshop-app/releases)).
